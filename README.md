# ClimateChain ID

Entry for the IEEE ClimateChain Global Hackathon 2026 (Track 4: Climate Data & Environmental Monitoring).

Working idea: Indonesian peatland fire / haze forecasting, with forecast provenance (model hash, data hash, IPFS CID) recorded on-chain in a `ForecastRegistry` contract on Polygon Amoy.

Status: planning. Deadline 25 Oct 2026, 07:00 PDT.
