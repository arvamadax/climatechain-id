On-chain proof

Every published check is on the record. No one, not even Netra, can edit it.

Each published check is anchored in the ClaimRegistry smart contract on the Ethereum Sepolia test network. Anyone can recompute the report from the open data and confirm it matches. Each claim commits to the registry serial ranges behind it; if one range shows up in two claims, anyone can prove it on-chain and the later claim is flagged for good.

Check it yourself in three steps

  1. Get the report. Each record points to its file, for example data/checks/4.json.
  2. Hash it. Take the report object in that file as JSON, exactly as stored, and compute its keccak256: keccak256(toUtf8Bytes(JSON.stringify(report)))
  3. Compare. On the block explorer, read the record: its report hash must be the same, and the serial list in the file must give its serial root. This page does both for every record above.

Who can do what

  • Publishing needs Netra's key. Only an address holding the attester role can record a check.
  • Flagging needs only proof. Anyone can challenge a record with two Merkle proofs; the contract checks them itself, so a wrong challenge fails.
  • No one can edit or delete a check. The contract has no function for it. The only change possible is the double-claim flag, and only with valid proofs.
  • What it does not prove. That a report is accurate, or that its serial ranges were retired as stated: the contract stores fingerprints and reads nothing outside itself.
